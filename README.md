# BuildMC Rules Repository

This repository contains the official rules for the **BuildMC** server and community.  
The rules are split into two main categories:

- `minecraft_rules.md` – Rules related to Minecraft gameplay, project-specific guidelines, and allowed mods.
- `discord_rules.md` – Rules for Discord server behavior, moderation, and voice channels.

## Purpose

This repository exists to allow the BuildMC team to **edit and maintain rules easily**.  
The bot fetches the raw markdown files to display them in Discord, so updates here are automatically reflected in the server.

## Contributing

1. Create a branch or fork.
2. Edit the relevant Markdown file.
3. Submit a pull request for review.
4. Once approved, merge into `main`.

> ⚠️ Only team members should edit these files directly.

## Notes

- Keep formatting in Markdown supported by Discord.
- Always test that changes render correctly in a Discord embed.
